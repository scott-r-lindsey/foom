## What wins when they disagree

The docs are the spec; the mockups show intent. When a mockup and a doc disagree, follow the doc.

- **Look:** `board.html` and `first-run.html` were drawn before the brand was chosen. Their grey and indigo palette and their fonts are placeholders. Take layout and behavior from them, and color and type from [brand.md](../brand.md), `src/renderer/tokens.css`, and `brand.html`.
- **`settings.html` uses the brand.** It was drawn after the brand and the sidebar decision (#88), so its colors are the tokens. Its Setup sections are placeholders for preflight's existing controls. Deep Field and the scheme list are proposals, and the terminal preview uses Hack Nerd Font Mono only if it is installed.
- **Tidy tiles (#265)** adds a seventh footer icon after the six presets in `tiles.html`, with the accessible name and tooltip “Tidy tiles”. Double-clicking a gutter or pressing Enter evens its same-axis run; Tidy removes spaces and evens all runs. The wordmark menu also adds View → Tidy tiles on every platform. The mockups predate these controls; [Terminal tiles](../product.md#terminal-tiles) defines their behavior.
- **`tile-panels.html` supersedes the tile chrome in `tiles.html`:** its title-bar buttons, its Hide session control and its empty tiles with title bars and numbers. Layout, presets, maximize and drag and drop (#133) still come from `tiles.html` and the docs. Its sidebar is a session list only, and terminal text is a picture.
- **`app-menu.html` is implemented (#226).** Tile, focus, swap and preset commands leave the wordmark menu; their shortcuts still work and are listed on the shortcut sheet. Every item ships now; anything not yet implemented is disabled, with no issue number or explanation, and is enabled when its issue lands: Action log (#157) and the three Via agent entries (#84). New orchestrator is removed: #303 replaced the orchestrator launch with Make orchestrator… on a running session's menu. About opens the native panel until the About screen (#96); until then the menu also keeps a **Third-party licenses** item after About, which the mockup omits, and its dialog links to the source repository. The macOS native menu bar keeps every command.
- **`tiles.html` supersedes the single pane** in `sidebar.html`. Its sidebar is a slice, without filter or menus, and it has no Preflight button: Preflight leaves the sidebar in #132.
- **`sidebar-panels.html` supersedes the ⋯ menus** in `sidebar.html` and the read-only review launches (#195). Its sidebar is otherwise a slice: no filter behavior, pins only on repositories, and terminal text is a picture. Theme colors come from `src/shared/interface-themes.ts`; the highlight values for Graphite, Deep Field and Moonlight are proposals for #196.
- **`sidebar.html` uses the brand and supersedes the flat sidebar** in `settings.html` and `board.html`. Agent badges (CC, CX, AG, `>_`) stand in until #112 decides on marks. The terminal text is a picture, and the menu actions don't do anything.
- **`brand.html` shows several variants.** Only Eclipse was picked (icon, wordmark, app look, and the light palette). The others were rejected.
- **`environment.html` adds one thing to #215:** a value with credentials in a URL (`user:pass@`) is always Secret, and its Secret toggle is locked on. A valid row saves when focus leaves it, and the status reads "Saved for new sessions"; running sessions keep the environment they started with. Validation in the mockup mirrors #215's rules but main is authoritative. The sidebar is a slice.
- **`new-worktree.html` replaces the New worktree dialog** (`src/renderer/board/worktree-dialog.tsx`). The repository is the panel's; ⌘T / Ctrl+Shift+T and the app menu open the focused tile's repository panel with the field focused. Spaces become `-`. Tab completes and Enter commits what is typed. A new branch starts from the repository's HEAD. An origin-only branch is checked out tracking origin, not created fresh. A branch checked out elsewhere skips creation and that worktree's row flares instead. Esc or Left on an empty field returns to New worktree. Creating never launches anything; focus moves to the new row, whose own panel offers the launchers. The arrival is the accent, never amber: nothing needs the user yet. With reduced motion the row keeps the tint and edge without animating.
- **`delete-merged.html` changes when the dialog opens and what Delete shows;** eligibility, retention reasons and the fresh fetch after Delete stay as `product.md` describes. Removal order and the four-at-a-time limit are illustrative; main decides. Removing is the highlight, never amber or magenta: nothing needs the user and nothing failed. A worktree that changed since the check is kept, not failed; a removal error uses the failure color. Escape and Hide close the window without stopping anything; Stop finishes the removals in flight and starts no more. A run that finishes while hidden clears the count and reports once. The sidebar is a slice, and terminal text is a picture.
- **`lights.html` changes how lights show output, exit and shells;** states, colors and their meanings stay as `product.md` describes. Glow + trace is chosen: the light's glow plus an eight-second output trace beside the session name in the sidebar (tile title bars get the glow only); Current and Glow alone remain for comparison. Output maps to the level logarithmically with a fast rise and slow fall, never above 3 Hz; reduced motion steps the level about once a second without animating. Only Working agents and running shells move; Needs you, Done and Quiet hold still. A ring means the process exited; a solid light means it is running. Shells show only the foreground program's name, never its arguments, and nothing at the prompt. Data and terminal text are illustrative, and the mockup panel is not app chrome.
- **`resume-conversation.html` replaces the bare resume field;** parsing, validation, the launch path and the rule that Foom never reads agent transcript files stay as `product.md` describes. The picker rows launch `claude --resume` and `codex resume` without an ID (each CLI's own picker, filtered to this folder) and `agy --continue`; Foom learns the conversation ID from hooks as for any launch. A bare ID suggests Codex only for a version 7 UUID and Claude Code only for version 4 when Antigravity is off; otherwise the user chooses. The "close it elsewhere" line is the only guard against a conversation still open outside Foom. Picker screens and IDs are illustrative, and the mockup panel is not app chrome.
- **Signals:** `board.html` shows "tty echo off" as a password signal. Research in [agents.md](../agents.md) rejected echo-off as an independent signal. Reasons and signals follow [product.md](../product.md) and the evaluator.
- **Fonts:** the mockups load fonts from Google Fonts. The app bundles its fonts and its CSP blocks remote ones.
- **Scope:** anything a mockup shows that no doc or issue describes (for example `⌘K` in `first-run.html`) isn't decided. Ask before building it.
- **`config-footer.html` moves Foom config out of the tree;** the panel's facts, the launchers, the one-session rule and the approval flow stay as `product.md` describes. The gear replaces the Settings button, and Settings becomes the panel's first command; ⌘, / Ctrl+, and the app menu still open Settings directly. The dock shows only while a change is held, files are rejected or the config session exists, and the held change still counts in "N need you". The gear's dot repeats the dock and is never the only signal: the dock's chips and the gear's accessible name carry the text. Clicking the dock's line or the gear opens the panel; clicking the docked session focuses its tile as any session row does. Data and terminal text are illustrative, and the mockup panel is not app chrome.
- **`sidebar-collapse.html` lets the user choose the compact rail;** the rail's content and the narrow-window breakpoint stay as they are today, plus a needs-you count at the top and the Foom config gear at the bottom (from #277; the dock's chips are not shown in the rail, so the gear's dot and accessible name carry a held change, and it still counts in "N need you"). Collapse is remembered per window. Below 720px the rail is forced; the header button reads Close sidebar there, and Open sidebar shows the full sidebar over the tiles until a click outside, Escape or the shortcut. Plain Ctrl+B is avoided because readline and tmux use it in terminals. Hiding the sidebar entirely is not offered: the rail keeps every light visible. Data and terminal text are illustrative, and the mockup panel is not app chrome.
- **`preview-tiles.html` draws previews for #221 and #222;** isolation, file serving, live reload and the agent preview tools stay as `docs/previews.md` and `docs/agent-previews.md` describe. The kind badge (MD, HTML) is the "Preview badge" those docs name. A preview takes focus only from a click on it: opening, an agent's open, reloads and navigation never move focus. An agent's preview never adds a column or replaces a tile; with no landing spot or empty space it waits as a row under the opener's session, and showing it from there follows the placement for anything you launch. Closing an agent's preview sticks: the same agent opening the same file again gets only a row. Allow network lasts until restart and only allows https. The confirmation names what the page can do. Link prompts show the full URL, one at a time per preview; requests made while one is open are dropped. The "snapshot" tag is a mockup annotation: in the app the frozen image looks exactly like the live page. Page content, file sizes and times are illustrative, and the mockup panel is not app chrome.
- **`dialogs.html` changes how trusted dialogs look, not what they ask;** which actions confirm, the click-again flow, focus, Escape, scrim and window clamping stay as `architecture.md` describes. The orchestrator disclosure keeps every clause of today's text, regrouped. Widths (500px, 540px with lists) are the intent; main still clamps the window. Removing is the highlight; only a failed removal uses the failure color, and Needs you keeps amber with its halo. Destructive accept buttons stay neutral: the verb names the effect. Glyphs, branch names, counts and the pairing code are illustrative; the gallery layout and the dimmed backdrops are mockup chrome.
- **`sidebar-footer.html` supersedes the footer bar** in `config-footer.html` and `tiles.html` (#362): the six presets and Tidy leave the footer and keep their shortcuts. Its dock above the bar and the Foom config panel still come from `config-footer.html`. Settings → Sound shows the same master volume first, above the working and alert volumes.
